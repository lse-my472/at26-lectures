# Week 4: Tabular data

This week covers tabular data, including NumPy arrays and pandas data frames, dates and categorical data, string methods and regular expressions, and reading/writing CSV and Excel files.

## Resources

- NumPy Developers. _NumPy User Guide_. [NumPy fundamentals](https://numpy.org/doc/stable/user/basics.html), especially [Data types](https://numpy.org/doc/stable/user/basics.types.html).

- McKinney, Wes. 2022. _Python for Data Analysis_, 3rd ed. Ch 5, [Getting Started with pandas](https://wesmckinney.com/book/pandas-basics.html).

- McKinney, Wes. 2022. _Python for Data Analysis_, 3rd ed. Ch 7, [Data Cleaning and Preparation](https://wesmckinney.com/book/data-cleaning.html) (§7.4, String Manipulation, especially).

- Python Software Foundation. [Regular Expression HOWTO](https://docs.python.org/3/howto/regex.html).

- pandas Development Team. _pandas User Guide_. [Time series / date functionality](https://pandas.pydata.org/docs/user_guide/timeseries.html), especially [Converting to timestamps](https://pandas.pydata.org/docs/user_guide/timeseries.html#converting-to-timestamps) and [Time/date components](https://pandas.pydata.org/docs/user_guide/timeseries.html#time-date-components). See also the [`.dt` accessor](https://pandas.pydata.org/docs/user_guide/basics.html#dt-accessor).

- Python Software Foundation. [`datetime` — Basic date and time types](https://docs.python.org/3/library/datetime.html), especially [Aware and naive objects](https://docs.python.org/3/library/datetime.html#aware-and-naive-objects) and the [format codes](https://docs.python.org/3/library/datetime.html#strftime-and-strptime-format-codes) for `strftime()` and `strptime()`.

- McKinney, Wes. 2022. _Python for Data Analysis_, 3rd ed. §6.1, [Reading and Writing Data in Text Format](https://wesmckinney.com/book/accessing-data.html#io_flat_files), and [Reading Microsoft Excel Files](https://wesmckinney.com/book/accessing-data.html#pandas_excel_files) in §6.2.
