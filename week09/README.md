# Week 9: APIs and remote computers

This week provides an introduction to getting data from the cloud via APIs, and to working on computers other than your own: containers and remote machines.

## Resources

- Python Software Foundation. `requests`. [Quickstart](https://requests.readthedocs.io/en/latest/user/quickstart/).

- GitHub. REST API: [Rate limits for the REST API](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api) and [Using pagination in the REST API](https://docs.github.com/en/rest/using-the-rest-api/using-pagination-in-the-rest-api).

- OpenAI. [API reference: responses](https://platform.openai.com/docs/api-reference/responses).

- Google. [Geocoding API overview](https://developers.google.com/maps/documentation/geocoding/overview).

- Neal, David. 2019. [An Illustrated Guide to OAuth and OpenID Connect](https://developer.okta.com/blog/2019/10/21/illustrated-guide-to-oauth-and-oidc). Okta Developer blog.

- OpenBSD. [`ssh(1)` manual page](https://man.openbsd.org/ssh.1).

- GitHub. [GitHub Codespaces overview](https://docs.github.com/en/codespaces/overview).

- Docker. [Docker overview](https://docs.docker.com/get-started/docker-overview/) and [What is a container?](https://docs.docker.com/get-started/docker-concepts/the-basics/what-is-a-container/).
