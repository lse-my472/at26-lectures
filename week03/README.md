# Week 3: Digital security

This week covers digital security, including hashing, encryption, authorisation and data access, authentication, and good security practice.

## Resources

- MIT. [The Missing Semester of Your CS Education, Lecture 9: Security and cryptography](https://missing.csail.mit.edu/2020/security/). Covers hash functions, key derivation, symmetric and asymmetric encryption, password managers, two-factor authentication and SSH.

- Meli, Michael, Matthew R. McNiece, and Bradley Reaves. 2019. [How bad can it Git? Characterizing secret leakage in public GitHub repositories](https://ndss-symposium.org/wp-content/uploads/2019/02/ndss2019_04B-3_Meli_paper.pdf). NDSS Symposium. A shorter [summary by Adrian Colyer](https://blog.acolyer.org/2019/04/08/how-bad-can-it-git-characterizing-secret-leakage-in-public-github-repositories/) is also available.

- Electronic Frontier Foundation. [Surveillance Self-Defense](https://ssd.eff.org/). The guides on strong passwords, password managers and encryption.
