# Week 5: Databases

This week covers databases, including filtering, summarising and grouping data in pandas, tidy data and normalisation, merging and joining tables, and querying a SQLite database with SQL from Python.

## Resources

- pandas Development Team. [_pandas Cheat Sheet_](https://pandas.pydata.org/Pandas_Cheat_Sheet.pdf). Two pages covering subsetting, reshaping, grouping and joining.

- Python Software Foundation. _Built-in Functions_, [`help()`](https://docs.python.org/3/library/functions.html#help). Prints the documentation for a function or other object. In the Positron Console, you can also type `?` after a name, as in `pd.merge?`. See IPython's [Exploring your objects](https://ipython.readthedocs.io/en/stable/interactive/tutorial.html#exploring-your-objects).
