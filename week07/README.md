# Week 7: Visualisation

This week covers visualisation, including what makes a figure good or bad, the grammar of graphics with `plotnine`, and spatial data.

## Resources

- Healy, Kieran. 2019. _Data Visualization: A Practical Introduction._ Ch. 1, [Look at Data](https://socviz.co/01-look-at-data.html).

- Tufte, Edward. 2001. _The Visual Display of Quantitative Information_. 2nd ed. A print book, not available online. Optional background.

- Wickham, Hadley, Mine Çetinkaya-Rundel and Garrett Grolemund. 2023. _R for Data Science_. 2nd ed. Chs. 1, 9, 10 and 11. Available at <https://r4ds.hadley.nz/>. The code is in R, but `plotnine` uses the same grammar and almost the same function names.

- [`plotnine` documentation](https://plotnine.org/).

- GeoPandas. [Introduction to GeoPandas](https://geopandas.org/en/stable/getting_started/introduction.html) and [Managing projections](https://geopandas.org/en/stable/docs/user_guide/projections.html).
