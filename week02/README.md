# Week 2: Digital data

This week covers the fundamentals of digital data, including bits and bytes, storage and memory, Python objects and mutability, reading and writing files, character encodings and tokenisation.

## Resources

- Computer Science Field Guide. [Numbers](https://www.csfieldguide.org.nz/en/chapters/data-representation/numbers/). Sections 5.3.1–5.3.3 on binary and hexadecimal. Optional background.

- Stanford CS101. [Computer hardware](https://web.stanford.edu/class/cs101/hardware-1.html). The sections on RAM and persistent storage. Optional background.

- Batchelder, Ned. [Facts and myths about Python names and values](https://nedbatchelder.com/text/names). The opening sections through “Assignment”, covering references, aliasing and mutability. Later function examples are optional.

- Python Software Foundation. [Reading and writing files](https://docs.python.org/3.13/tutorial/inputoutput.html#reading-and-writing-files). Sections 7.2 and 7.2.1 on file modes, `with`, reading and writing. The JSON section is not needed this week.

- Zentgraf, David C. n.d. [What every programmer absolutely, positively needs to know about encodings and character sets to work with text](https://kunststube.net/encoding/).

- Python Software Foundation. [Unicode HOWTO](https://docs.python.org/3.13/howto/unicode.html). Focus on “Introduction”, “The String Type”, “Converting to Bytes” and “Reading and Writing Unicode Data”.

- Jurafsky, Daniel, and James H. Martin. [Speech and Language Processing, chapter 2](https://web.stanford.edu/~jurafsky/slp3/2.pdf). Section 2.4, “Subword Tokenization: Byte-Pair Encoding”.

- Hugging Face. [Byte-Pair Encoding tokenization](https://huggingface.co/learn/llm-course/en/chapter6/5). A worked example of BPE. Read the explanation before “Implementing BPE”; the implementation is optional.
