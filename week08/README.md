# Week 8: Scraping webpages

This week covers the ethics of collecting data online and the basics of scraping webpages, including an overview of the mechanics of website source code and query languages.

## Resources

- Severance, Charles Russell. 2015. [_Introduction to Networking: How the Internet Works_](http://www.net-intro.com).

- Howe, Shay. 2015. [_Learn to Code HTML and CSS: Develop and Style Websites_](http://learn.shayhowe.com/html-css/). Chs 1-8.

- Richardson, Leonard. [_Beautiful Soup Documentation_](https://www.crummy.com/software/BeautifulSoup/bs4/doc/), especially "Making the soup", "Searching the tree" and "CSS selectors".

- [CSS selectors reference](https://www.w3schools.com/cssref/css_selectors.asp).

- [XPath syntax](https://www.w3schools.com/xml/xpath_syntax.asp).
